# RULLZYE CLOUD — Public Website for Netlify

Ini adalah paket website publik (*Public Client Portal*) yang terhubung dengan **RULLZYE CLOUD Private Storage API** di **Render**.

## 🚀 Panduan Deploy ke Netlify:

### Cara 1: Netlify Drop (Paling Mudah - Tanpa Coding)
1. Buka [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Seret (*drag & drop*) seluruh folder hasil ekstraksi ini ke area unggah Netlify Drop.
3. Tunggu beberapa detik, dan website publik Anda langsung Aktif!

### Cara 2: Via GitHub / Netlify CLI
1. Push folder ini ke repositori GitHub baru Anda.
2. Hubungkan ke Netlify via tombol **New site from Git**.
3. Set Publish Directory: `.`
4. Klik **Deploy site**.

---

## ⚙️ Pengaturan URL Server Backend Privat:
Secara default, website publik ini terhubung ke origin API RULLZYE CLOUD.
Jika server privat RULLZYE CLOUD Anda di-deploy ke **Render** (misalnya `https://rullzye-cloud.onrender.com`), Anda dapat mengubah URL server kapan saja dengan menekan ikon **Pengaturan (⚙️)** di pojok kanan atas website publik ini.
