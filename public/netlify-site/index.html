Unduh file, putar video, dan tampilkan foto secara langsung dari server privat yang terhubung melalui API RESTful.

Dokumentasi API RESTful (v1)

Gunakan Endpoint API berikut untuk menghubungkan website Netlify atau aplikasi eksternal lainnya ke Server Storage Privat RULLZYE CLOUD di Render.

GET /api/v1/public/status

Mendapatkan status server, total file, dan ketersediaan storage.

GET /api/v1/public/files?search=&type=ALL

Mengambil daftar file publik lengkap dengan URL download dan streaming.

GET /api/v1/public/media?category=PHOTOS

Mengambil daftar media berstruktur khusus untuk galeri website publik.

GET /api/v1/public/download/{id}?inline=true

Mengalirkan (*stream*) atau mengunduh media langsung dari Cloud Storage Telegram melalui server privat Render.

GET /api/v1/public/project-export

Unduh Website Publik Siap Deploy ke Netlify

Paket file website publik terpisah yang terhubung dengan API Server Privat di Render.

Paket Kode (.ZIP)

File ZIP ini berisi `index.html`, `app.js`, `styles.css`, `api-docs.html`, dan `netlify.toml` yang sudah terkonfigurasi.

Langkah Deploy ke Netlify

  1. Unduh file ZIP project melalui tombol di samping.
  2. Ekstrak file `.zip` tersebut di komputer atau HP Anda.
  3. Buka app.netlify.com/drop.
  4. Tarik & lepaskan (*drag and drop*) folder hasil ekstrak ke Netlify Drop.
  5. Website Publik Anda langsung online di Netlify dalam beberapa detik!
